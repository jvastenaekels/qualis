# GDPR documentation for self-hosters

Qualis provides technical controls that can support an operator's compliance work.
The institution operating an instance remains responsible for determining its legal
bases, retention schedule, processors, transfers, notices, and response procedures.

> This documentation describes software behavior and operational considerations.
> It is not legal advice.

Choose the document that matches your immediate need:

| Need | Document |
| ---- | -------- |
| Understand who is responsible and where data crosses trust boundaries | [GDPR responsibility model](../explanation/gdpr-responsibility-model.md) |
| Handle access, erasure, incidents, retention, or DPIA work | [GDPR operations guide](../guides/gdpr-operations.md) |
| Look up stored data, lifecycle behavior, controls, and article mappings | [GDPR controls reference](gdpr-controls.md) |
| Start an Article 30 record for one deployment | [Record-of-processing template](templates/record-of-processing.md) |

Operators should review these documents with their data-protection officer or legal
counsel and adapt them to the actual deployment and research protocol.
