# Test run sans bug — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un `Test run` ne peut jamais devenir une vraie session, ne bloque plus, montre l'étude dans la langue choisie et dit honnêtement que rien n'est gardé.

**Architecture:** toute la protection reste côté navigateur : le serveur ne connaît pas le test, et `/submit` crée une ligne pour un jeton inconnu. Une seule règle : un onglet de test reste en test. Le drapeau `qualis-pilot-mode` (sessionStorage) tranche : si `?mode=test` disparaît, le layout le remet ; on ne sort du test que par le bouton du bandeau. Le sens sûr de l'erreur est donc « encore en test », jamais « réel par accident ».

**Tech Stack:** React 19, React Router 7, Zustand, TanStack Query, i18next, Vitest, Playwright.

**Spec:** audit du 2026-11-05, résumé dans ce plan ; décisions validées par Julien : règle ci-dessus, `?mode=test` sans brouillon local refusé.

## Global Constraints

- Un test ne doit jamais atteindre `POST` consent, progress, save-draft, audio ou submit. Aucune garde existante n'est affaiblie : `isPilotModePersistent`, le re-verrouillage de `restoreStudySession`, le protocole `qualis-pilot-reset-<slug>`.
- Les noms des stores (`qualis-pilot-session`, `qualis-pilot-responses`) sont fixés au chargement du module : aucune décision de mode ne peut venir après.
- Texte affiché : `t('key', 'Fallback')`. Parité stricte de `participant.json` dans les 9 langues. Les nouvelles chaînes en finnois sont à faire relire.
- Pas de drapeau de test côté serveur, pas d'aperçu calculé par le serveur.
- Biome : pas de `any` nouveau. E2E : base jetable, `make ... DATABASE_URL=...` en argument de make, jamais en préfixe.

## Review Focus

1. **Vrai lien collé dans un ancien onglet de test.** Il reste en test, le bandeau le dit, et le bouton de sortie mène à une vraie session propre (test en tâche 1).
2. **Rechargement à chaque étape du test.** Ni page bloquée, ni réponses perdues, ni écriture serveur (test en tâche 1).
3. **Étude finnoise seule.** Le test s'ouvre en finnois, sans carte vide, et aucun menu ne propose `en` (test en tâche 2).
4. **Étude active testée de bout en bout.** Aucune ligne participant n'apparaît (test en tâche 5).
5. **Modification dans le designer pendant un test.** L'onglet de test garde sa page et affiche un avis (test en tâche 4).
